# רשת ב׳ – כאן 📻

אפליקציית ווב פשוטה (PWA) להאזנה חיה לתחנת הרדיו **רשת ב׳** של תאגיד השידור הישראלי **כאן**.

## תיאור

האפליקציה היא עמוד HTML יחיד, ללא צורך בשרת או בבנייה (build), המספק נגן רדיו אינטרנט מינימליסטי בעיצוב "וינטג׳" חם (גוונים כהים וענבר). האפליקציה תומכת בעברית מלאה עם כיווניות RTL.

### תכונות עיקריות

- **נגן רדיו חי** – הפעלה/השהיה בלחיצת כפתור יחיד, עם מעבר אוטומטי בין מספר כתובות שידור (streams) חלופיות במקרה של תקלה בחיבור.
- **בקרת עוצמת קול** – מחוון (slider) לשליטה בווליום הנגן.
- **חיווי מצב חי** – נורית סטטוס, אנימציית "מד VU" (פסי עוצמת קול קופצים) וספינר טעינה בזמן חיבור לשידור.
- **הפעלה אוטומטית ב-Bluetooth** – ניתן להגדיר שם של התקן Bluetooth (למשל מערכת השמע ברכב), והאפליקציה תזהה חיבור אליו ותתחיל לנגן אוטומטית.
- **PWA מלא** – ניתן להתקין את האפליקציה כאייקון על מסך הבית (במובייל או בדסקטופ) באמצעות `manifest.json`, עובדת גם עם מסך פתיחה מותאם אישית.
- **Service Worker** – שומר במטמון (cache) את קבצי הליבה של האפליקציה לטעינה מהירה ולעבודה חלקית גם ללא חיבור לרשת (השידור החי עצמו כמובן דורש אינטרנט).
- **מניעת כיבוי מסך** – שימוש ב-Wake Lock API כדי למנוע מהמסך להיכבות בזמן האזנה (במכשירים התומכים בכך).

## מבנה הפרויקט

```
radiob/
├── index.html      # כל האפליקציה: מבנה, עיצוב (CSS) ולוגיקה (JavaScript)
├── manifest.json   # הגדרות ה-PWA (שם, אייקונים, צבעים, מצב תצוגה)
├── sw.js           # Service Worker לשמירה במטמון ותמיכה בעבודה אופליין
└── icons/          # אייקוני האפליקציה בגדלים שונים
```

## שימוש

מכיוון שמדובר בעמוד סטטי בלבד, ניתן להריץ אותו ישירות על ידי שרת קבצים סטטי כלשהו, לדוגמה:

```bash
npx serve .
```

ולפתוח את הכתובת שתתקבל בדפדפן. לחלופין ניתן לפרוס את הקבצים על כל שירות אחסון סטטי (GitHub Pages, Netlify, Vercel וכדומה).

להתקנה כאפליקציה במכשיר נייד – יש לפתוח את האתר בדפדפן ולבחור באפשרות "הוסף למסך הבית" / "התקן אפליקציה".
